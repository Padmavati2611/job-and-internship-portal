CareerConnect – Job and Internship Portal

CareerConnect is a web-based platform designed to help students discover job opportunities and internships, apply for positions, and manage their applications in one place.

The platform aims to simplify the job search process and connect students with career opportunities.

🚀 Features
Browse available jobs and internships.
Discover career opportunities.
Apply for suitable job and internship positions.
Track application status.
User-friendly and responsive interface.
Easy navigation and application management.

⚙️ Installation and Setup
1. Clone the repository
bash
git clone https://github.com/Padmavati2611/job-and-internship-portal.git

2. Navigate to the project folder
bash
cd job-and-internship-portal

3. Navigate to the frontend
bash
cd frontend

4. Install dependencies
bash
npm install

5. Start the development server
bash
npm run dev

6. Open in browser

Visit the local URL displayed in your terminal, usually:

text
http://localhost:5173/
